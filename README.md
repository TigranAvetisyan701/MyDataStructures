# Data Structures and Algorithms in C#

A collection of C# projects exploring fundamental data structures, algorithms, and their practical implementations.

## Overview

This repository contains projects developed during my university's **Data Structures I** semester course.

The projects document my learning process and practical implementation of fundamental data structures and algorithms using C#. They were created as part of my academic coursework to strengthen my understanding of data organization, algorithmic thinking, and object-oriented programming.

## Topics Covered

| Category | Projects |
|---|---|
| Linked Structures | Linked List |
| Hashing | Hash Table |
| Linear Structures | Stack, Queue |
| Priority Structures | Priority Queue |
| Tree Structures | Binary Tree |
| Collections | Set |
| Algorithms | Sorting |
| Applications | Chessboard |
